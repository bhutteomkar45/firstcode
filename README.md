# Programs Included
🔹 Basic Programs

-Hello World
Prints Hello, World! using Console.WriteLine().

-Print Numbers Till 10
Prints numbers from 1 to 10.

-Even Numbers Till 10
Prints all even numbers between 1 and 10.

-Square of Numbers Till 10
Prints the square of numbers from 1 to 10.

🔹 Mathematical Programs

-Arithmetic Operations
Performs basic arithmetic operations (Addition, Subtraction, Multiplication, Division).

-Find Maximum Number (3 Numbers)
Finds the largest number among three inputs.

-Guess the Biggest Number
Compares three numbers and determines the biggest one.

-Factorial Program
Calculates the factorial of a given number.

-Addition of Digits
Adds the digits of a number.

🔹 Number Logic Programs

-Reverse Integer
Reverses a given integer number.

-Palindrome Number
Checks whether a number is a palindrome or not.

FizzBuzz Program
Classic FizzBuzz logic implementation.

-Count Digits in a Number
Counts the number of digits in a given integer.

🔹 String & Array Programs

-Traverse String
Traverses and prints characters of a string.

-Reverse Array
Takes an array input and prints the reversed array.
